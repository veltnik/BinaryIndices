# BinaryIndices ⁰¹²³₄₅₆₇

Простая и легковесная утилита для Windows на C# (.NET), которая позволяет быстро набирать верхние (степени) и нижние индексы без использования сложных сочетаний клавиш. Идеально подходит для работы с двоичной системой счисления, математическими формулами и конспектами.

## 🚀 Как это работает

Программа отслеживает состояние клавиши **Caps Lock**:

* **Caps Lock ВКЛЮЧЕН** + нажатие цифры `0-9` ➡️ **Верхний индекс** (Степени: `¹ ² ³ ⁴`)
* **Caps Lock ВКЛЮЧЕН** + удержание **Shift** + цифра `0-9` ➡️ **Нижний индекс** (Основания систем: `₁ ₂ ₃ ₄`)
* **Caps Lock ВЫКЛЮЧЕН** ➡️ Стандартный ввод цифр и спецсимволов (`1 2 3 ! @ #`), программа никак не мешает повседневной работе.

## 💾 Быстрая установка (Рекомендуется)

1. Перейдите в раздел **[Releases](../../releases)** на панели справа и скачайте последний доступный архив или файл `BinaryIndices.exe`.
2. Запустите файл **от имени Администратора** (это необходимо, чтобы Windows разрешила программе перехватывать и заменять ввод клавиш).

---

## 🛠 Сборка и установка из исходников

Если вы хотите скомпилировать проект самостоятельно:

### Требования
* Установленный **.NET SDK** (версии 10.0 или новее).
* Редактор кода (например, **VS Code** с расширением *C# Dev Kit*).

### Инструкция по сборке:
1. Клонируйте репозиторий или скачайте исходный код архивом.
2. Откройте папку проекта в VS Code (**обязательно запустите сам VS Code от имени Администратора**).
3. Откройте встроенный терминал (`Ctrl + \``) и соберите проект командой:
   ```bash
   dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
   ```
4. Перейдите в созданную папку с готовой сборкой:
   `bin/Release/net10.0-windows/win-x64/publish/`
5. Запустите скомпилированный файл `BinaryIndices.exe`.

## 🔄 Настройка автозагрузки

Чтобы программа автоматически включалась при старте компьютера:

1. Нажмите комбинацию клавиш `Win + R`, введите команду `shell:startup` и нажмите *Enter*. Откроется папка автозагрузки Windows.
2. Нажмите правой кнопкой мыши по файлу `BinaryIndices.exe` и выберите **Создать ярлык**.
3. Перенесите созданный ярлык в открывшуюся папку автозагрузки.
4. Нажмите по ярлыку правой кнопкой мыши -> **Свойства** -> кнопка **Дополнительно** -> поставьте галочку **«Запуск от имени администратора»** -> Нажмите *ОК*.
