# BinaryIndices ⁰¹²³₄₅₆₇

Простая и легковесная утилита для Windows на C# (.NET), которая позволяет быстро набирать верхние (степени) и нижние индексы без использования сложных сочетаний клавиш. Отлично подходит для работы с двоичной системой счисления и математическими формулами.

## 🚀 Как это работает

Программа использует переключатель **Caps Lock** в качестве режима ввода индексов:

* **Caps Lock ВКЛЮЧЕН** + нажатие цифры `0-9` ➡️ **Верхний индекс** (Степени: `¹ ² ³ ⁴`)
* **Caps Lock ВКЛЮЧЕН** + удержание **Shift** + цифра `0-9` ➡️ **Нижний индекс** (Основания систем: `₁ ₂ ₃ ₄`)
* **Caps Lock ВЫКЛЮЧЕН** ➡️ Стандартный ввод цифр и спецсимволов (`! @ # $`), программа не мешает обычной работе.

## 🛠 Установка и запуск

1. Скомпилируйте проект в VS Code с помощью команды:
   ```bash
   dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
   ```
2. Запустите готовый файл `BinaryIndices.exe` из папки `bin/Release/.../publish/` **от имени Администратора** (это необходимо для работы глобального перехвата клавиш Windows).

## 🔄 Автозагрузка
Чтобы программа запускалась сама при старте Windows, нажмите `Win + R`, введите `shell:startup` и перенесите туда ярлык скомпилированного файла. В свойствах ярлыка укажите «Запускать от имени администратора».
